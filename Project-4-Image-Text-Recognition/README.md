# 🌈 VisionForge — AI Image & Text Recognition Dashboard

A professional **Project 4** for the **DecodeLabs Artificial Intelligence Internship**.  
This project performs **Image Recognition, Object Detection, and OCR Text Recognition** using modern AI libraries and an advanced React dashboard.

---

## 🚀 Features

- 🔐 Glassmorphism Sign In / Sign Up page
- ✨ Demo Login system
- 🌈 Animated rainbow LED border effects
- 🧠 Real object detection using COCO-SSD
- 🔤 OCR text recognition using Tesseract.js
- 📦 Image upload support
- 🖼️ Demo image analysis
- 🎯 Bounding boxes with object labels
- 📊 Confidence score display
- 📈 Performance analytics dashboard
- 🟢 Live activity monitoring
- 🔄 Working reset button
- 📱 Fully responsive UI
- ⚡ Built with React + Vite

## 🧠 Project Objective

The goal of this project is to implement a basic image or text recognition task using available AI libraries and display the output clearly.

---

## ✅ Requirement Mapping

| Requirement | Implementation |
|---|---|
| Use pre-trained model or simple library | COCO-SSD, TensorFlow.js, Tesseract.js |
| Perform recognition on sample input | Upload image or use demo image |
| Display output clearly | Bounding boxes, object labels, confidence scores, OCR text |
| Understand model output | Confidence filtering, live results, analytics dashboard |
